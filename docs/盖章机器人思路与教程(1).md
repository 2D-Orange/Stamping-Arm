# **3. 机器人结构设计**

## **3.1 机器人构型**

建议设计成一个简单的 4 自由度桌面机械臂：

| **关节编号** | **类型**   | **功能**     |
| ------------ | ---------- | ------------ |
| 关节 1       | 转动关节 R | 底座水平旋转 |
| 关节 2       | 转动关节 R | 大臂俯仰     |
| 关节 3       | 转动关节 R | 小臂俯仰     |
| 关节 4       | 移动关节 P | 印章上下按压 |

所以整体是：

**R-R-R-P 四自由度盖章机器人**

其中前三个关节负责把印章移动到目标位置附近，第四个移动关节专门负责下压盖章。

这个结构比 4R 机械臂更适合“盖章”任务，因为盖章动作本质上是竖直按压。

------

## **3.2 简化几何模型**

计划设置机械臂尺寸为：

| **参数**    | **含义**                                                 | **数值**    |
| ----------- | -------------------------------------------------------- | ----------- |
| $L_1$       | 底座高度                                                 | 0.105 m     |
| $L_2$       | 大臂长度                                                 | 0.25 m      |
| $L_3$       | 小臂长度                                                 | 0.30 m      |
| $L_{axis}$  | 小臂末端旋转关节轴到印章竖直移动关节轴的水平距离         | 0.025 m     |
| $H_{stamp}$ | $q_4=0$ 时，印章工作面与小臂末端关节的竖直高度差         | 0.015 m     |
| $q_4$       | 印章沿竖直移动关节向下伸长量                             | 0 到 0.07 m |

其中，$L_{axis}$ 与印章轴线、小臂位于同一个竖直平面内；印章轴线始终保持竖直，$L_{axis}$ 始终保持水平。$H_{stamp}$ 表示印章完全向上收起时，印章工作面（底面）相对小臂末端关节向下的高度差；$q_4$ 为第四个移动关节的向下伸长量。本简化模型默认 $L_{axis}$ 从小臂末端关节沿径向向外指向印章移动关节轴。


工作平面设定：

- 桌面高度：$z=0$
- 印泥接触点：$(0.20,\ 0.15,\ 0.02)$
- 文件盖章点：$(0.25,\ -0.15,\ 0.02)$
- 安全高度：印章工作面 $z=0.12$

# **4. 任务流程设计**

盖章机器人的完整动作可以分为 8 个阶段：

| **阶段** | **动作**         | **末端目标** |
| -------- | ---------------- | ------------ |
| 1        | 初始等待         | home         |
| 2        | 移动到印泥盒上方 | ink_above    |
| 3        | 下降蘸印泥       | ink_press    |
| 4        | 抬起             | ink_above    |
| 5        | 移动到文件上方   | paper_above  |
| 6        | 下降盖章         | paper_press  |
| 7        | 抬起             | paper_above  |
| 8        | 返回初始位置     | home         |

为了避免碰撞，所有水平移动都在安全高度完成。
 所以真正的轨迹可以设计为：

$home \rightarrow ink\_above \rightarrow ink\_press \rightarrow ink\_above \rightarrow paper\_above \rightarrow paper\_press \rightarrow paper\_above \rightarrow home$

其中：

- `ink_above` 是印泥盒正上方；
- `ink_press` 是印章接触印泥的位置；
- `paper_above` 是文件盖章点正上方；
- `paper_press` 是印章接触文件的位置。

# **5. 建模方法**

## **5.1 坐标系设定**

建立基坐标系：

- X：桌面前方
- Y：桌面左方
- Z：竖直向上

机械臂底座固定在桌面上，末端印章始终尽量保持竖直向下。

------

## **5.2 非标准 D-H 建系思路**

由于本机器人要求印章轴线始终竖直，而小臂会随 $q_2$、$q_3$ 俯仰，如果直接使用标准串联 D-H 表，末端印章会跟着小臂一起倾斜，不符合盖章机构的实际约束。因此这里采用**非标准 D-H 建系**：前三个转动关节仍用齐次变换描述，末端处额外设置一个姿态补偿坐标系，使印章移动关节轴恢复竖直。

各坐标系定义如下：

- $\{0\}$：基坐标系，原点在底座中心，$Z_0$ 竖直向上；
- $\{1\}$：底座旋转后的坐标系，原点在肩关节处，$X_1$ 指向机械臂当前径向外侧；
- $\{2\}$：大臂末端坐标系，随 $q_2$ 在径向竖直平面内俯仰；
- $\{3\}$：小臂末端坐标系，随 $q_3$ 相对大臂继续俯仰；
- $\{a\}$：印章竖直移动关节轴坐标系，通过姿态补偿使 $Z_a$ 重新竖直向上；
- $\{4\}$：印章工作面坐标系，原点在印章底面中心。

采用的非标准齐次变换为：

$T_{01}=T_z(L_1)R_z(q_1)$

$T_{12}=R_y(-q_2)T_x(L_2)$

$T_{23}=R_y(-q_3)T_x(L_3)$

$T_{3a}=R_y(q_2+q_3)T_x(sL_{axis})$

$T_{a4}=T_z[-(H_{stamp}+q_4)]$

其中 $s=1$ 表示印章移动关节轴位于小臂末端关节的径向外侧；如果实际结构安装在径向内侧，可取 $s=-1$。

总变换为：

$T_{04}=T_{01}T_{12}T_{23}T_{3a}T_{a4}$

这样建系后，$L_{axis}$ 始终保持水平，印章移动关节轴始终保持竖直，$q_4$ 始终表示印章向下伸长量。

# **6. 逆运动学简化方案**

为了让项目容易落地，我建议不要一开始就做复杂的通用数值逆运动学，而是使用**几何逆运动学**。

## **6.1 印章工作面目标点**

设印章工作面目标点为：

$P=(x,y,z)$

其中 $z$ 表示印章底面希望到达的高度。

底座关节角：

$q_1=\text{atan2}(y,x)$

第四关节 $q_4$ 用于按压，可以直接设置：

- 抬起时：$q_4=0$
- 下压时：$q_4=q_{4,press}$

其中 $q_{4,press}$ 不超过 0.07 m，可以设置为 0.07 m。

由于印章工作面不在小臂末端关节处，需要先把印章工作面目标点反推成小臂末端关节目标点。设印章工作面的水平半径为：

$r_e=\sqrt{x^2+y^2}$

小臂末端关节对应的水平半径为：

$r=r_e-L_{axis}$

因此目标点需要满足 $r_e>L_{axis}$，否则小臂末端关节会被反推到基座中心以内，不符合这个简化几何模型。

如果实际安装时印章移动关节轴位于小臂末端关节的径向内侧，只需要把上式改成 $r=r_e+L_{axis}$。

小臂末端关节对应的高度为：

$z_w=z+H_{stamp}+q_4$

将三维问题投影到机械臂的垂直平面内：

$z'=z_w-L_1$

对于大臂和小臂构成的二连杆机构，有：

$D=\frac{r^2+z'^2-L_2^2-L_3^2}{2L_2L_3}$

$q_3=\text{atan2}\left(\sqrt{1-D^2},D\right)$

$q_2=\text{atan2}(z',r)-\text{atan2}(L_3\sin q_3,L_2+L_3\cos q_3)$

# **7. 轨迹规划方法**

## **7.1 推荐使用五次多项式轨迹**

每个关节从初始角度 q_0 运动到目标角度 q_f，要求起点和终点速度、加速度均为 0。这样机械臂运动更平滑。

五次多项式形式为：

$q(t)=a_0+a_1t+a_2t^2+a_3t^3+a_4t^4+a_5t^5$

边界条件：

$q(0)=q_0,\quad q(T)=q_f$

$\dot q(0)=0,\quad \dot q(T)=0$

$\ddot q(0)=0,\quad \ddot q(T)=0$

可直接使用归一化形式：

$s(\tau)=10\tau^3-15\tau^4+6\tau^5$

其中：

$\tau=\frac{t}{T}$

则：

$q(t)=q_0+(q_f-q_0)s(\tau)$

这样就不需要手动求$a_0\sim a_5$。

# **8. 控制器设计**

## **8.1 建议采用关节空间 PD 控制**

控制目标是让实际关节角 q 跟踪期望轨迹 $q_d$。

定义误差：

$e=q_d-q$

$\dot e=\dot q_d-\dot q$

PD 控制律：

$\tau=K_p e+K_d \dot e$

对于第四个移动关节，可以认为控制输入是沿竖直方向的驱动力，也可以统一记作控制量。

在简化仿真中，可以用二阶关节模型：

$\ddot q=\tau$

也就是暂时忽略真实机器人复杂动力学，把每个关节近似看作单位惯量系统。这样对于课程大作业足够清楚，而且容易仿真。

------

## **8.2 可选：计算力矩控制**

如果你想让报告更高级，可以写：

$\tau=M(q)\left(\ddot q_d+K_d\dot e+K_pe\right)+C(q,\dot q)\dot q+G(q)$

但实际代码不一定要实现完整动力学。
 课程作业里采用 PD 控制已经足够。

```matlab
%  函数 1: 几何逆运动学

function q = inverse_kinematics_stamp(x, y, z, pressFlag, ...
    L1, L2, L3, L_axis, H_stamp, q4_press)

    q4 = pressFlag * q4_press;

    q1 = atan2(y, x);

    r_end = sqrt(x^2 + y^2);
    r = r_end - L_axis;  % 默认印章轴在腕部关节的径向外侧
    z_wrist = z + H_stamp + q4;
    zp = z_wrist - L1;

    D = (r^2 + zp^2 - L2^2 - L3^2) / (2 * L2 * L3);

    % 防止数值误差导致 D 超出 [-1, 1]
    D = max(min(D, 1), -1);

    q3 = atan2(sqrt(1 - D^2), D);

    q2 = atan2(zp, r) - atan2(L3 * sin(q3), L2 + L3 * cos(q3));

    q = [q1, q2, q3, q4];
end

%% ============================================================
%  函数 2: 五次多项式轨迹规划
%% ============================================================
function [q, qdot, t] = quintic_segment(q0, qf, T, dt)

    t = 0:dt:T;
    tau = t / T;

    s = 10*tau.^3 - 15*tau.^4 + 6*tau.^5;
    sdot = (30*tau.^2 - 60*tau.^3 + 30*tau.^4) / T;

    q = zeros(length(t), length(q0));
    qdot = zeros(length(t), length(q0));

    for i = 1:length(q0)
        q(:,i) = q0(i) + (qf(i)-q0(i)) * s';
        qdot(:,i) = (qf(i)-q0(i)) * sdot';
    end
end

%% ============================================================
%  函数 3: 非标准 D-H 正运动学
%% ============================================================
function [p0, p1, p2, p3, p_axis, p4] = forward_kinematics_stamp(q, ...
    L1, L2, L3, L_axis, H_stamp)

    q1 = q(1);
    q2 = q(2);
    q3 = q(3);
    q4 = q(4);

    % 非标准 D-H 齐次变换链
    T01 = trans_z(L1) * rot_z(q1);
    T12 = rot_y(-q2) * trans_x(L2);
    T23 = rot_y(-q3) * trans_x(L3);
    T3a = rot_y(q2 + q3) * trans_x(L_axis);
    Ta4 = trans_z(-(H_stamp + q4));

    T02 = T01 * T12;
    T03 = T02 * T23;
    T0a = T03 * T3a;
    T04 = T0a * Ta4;

    p0 = [0; 0; 0];
    p1 = T01(1:3,4);
    p2 = T02(1:3,4);
    p3 = T03(1:3,4);
    p_axis = T0a(1:3,4);
    p4 = T04(1:3,4);
end

function T = trans_x(a)
    T = eye(4);
    T(1,4) = a;
end

function T = trans_z(d)
    T = eye(4);
    T(3,4) = d;
end

function T = rot_y(theta)
    c = cos(theta);
    s = sin(theta);
    T = eye(4);
    T(1:3,1:3) = [
         c, 0, s
         0, 1, 0
        -s, 0, c
    ];
end

function T = rot_z(theta)
    c = cos(theta);
    s = sin(theta);
    T = eye(4);
    T(1:3,1:3) = [
        c, -s, 0
        s,  c, 0
        0,  0, 1
    ];
end

%% ============================================================
%  函数 4: 绘制机器人
%% ============================================================
function draw_stamp_robot(q, L1, L2, L3, L_axis, H_stamp)

    [p0, p1, p2, p3, p_axis, p4] = forward_kinematics_stamp(q, ...
        L1, L2, L3, L_axis, H_stamp);

    points = [p0, p1, p2, p3, p_axis, p4];

    plot3(points(1,:), points(2,:), points(3,:), '-o', ...
        'LineWidth', 3, 'MarkerSize', 6);

    % 印章画成竖直圆柱，底面为 p4
    [X,Y,Z] = cylinder(0.015, 12);
    Z = Z * (H_stamp + q(4));
    X = X + p4(1);
    Y = Y + p4(2);
    Z = Z + p4(3);
    surf(X, Y, Z, 'FaceAlpha', 0.6, 'EdgeColor', 'none');
end

%% ============================================================
%  函数 5: 绘制桌面场景
%% ============================================================
function draw_table_scene()

    % 桌面
    [X, Y] = meshgrid(-0.1:0.1:0.45, -0.3:0.1:0.3);
    Z = zeros(size(X));
    surf(X, Y, Z, 'FaceAlpha', 0.15, 'EdgeColor', 'none');
    hold on;

    % 印泥盒
    plot3(0.20, 0.15, 0.01, 's', 'MarkerSize', 14, 'LineWidth', 2);
    text(0.20, 0.17, 0.03, '印泥盒');

    % 文件盖章点
    plot3(0.25, -0.15, 0.01, 'p', 'MarkerSize', 16, 'LineWidth', 2);
    text(0.25, -0.13, 0.03, '文件盖章点');

    % 文件区域
    fill3([0.18 0.35 0.35 0.18], [-0.22 -0.22 -0.08 -0.08], ...
          [0.002 0.002 0.002 0.002], [0.8 0.8 0.8], 'FaceAlpha', 0.5);
end
```

# **13. CoppeliaSim 进阶仿真路线**

## **13.1 CoppeliaSim 中搭建场景**

需要添加：

| **对象**     | **建议做法**       |
| ------------ | ------------------ |
| 桌面         | 添加 cuboid        |
| 机械臂底座   | cylinder           |
| 大臂、小臂   | cuboid 或 cylinder |
| 关节         | revolute joint     |
| 末端按压关节 | prismatic joint    |
| 印章         | cylinder 或 cuboid |
| 印泥盒       | cuboid             |
| 文件         | thin cuboid        |
| 盖章目标点   | 小圆点或贴图       |

## **13.2 关节设置**

前三个关节设置为：

- revolute joint；
- mode 设为 position control；
- 关节角范围根据设计设置。

第四个关节设置为：

- prismatic joint；
- mode 设为 position control；
- 位移范围 0 到 0.07 m；
- 移动方向保持竖直向下，印章轴线与小臂处于同一竖直平面。

## **13.3 Python 控制 CoppeliaSim**

安装依赖：

```bash
pip install coppeliasim-zmqremoteapi-client
```

Python 控制框架大致如下：

```python
from coppeliasim_zmqremoteapi_client import RemoteAPIClient
import time
import numpy as np

client = RemoteAPIClient()
sim = client.require('sim')

joint_names = [
    '/joint1',
    '/joint2',
    '/joint3',
    '/joint4'
]

joints = [sim.getObject(name) for name in joint_names]

sim.startSimulation()

# 示例轨迹点
trajectory = [
    [0.0, 0.2, 0.5, 0.0],
    [0.5, 0.1, 0.6, 0.0],
    [0.5, 0.1, 0.6, 0.03],
    [0.5, 0.1, 0.6, 0.0],
]

for q in trajectory:
    for i in range(4):
        sim.setJointTargetPosition(joints[i], q[i])
    time.sleep(1.0)

sim.stopSimulation()
```

注意：CoppeliaSim 的关节对象名称必须和代码里的 `/joint1`、`/joint2` 等一致。
 如果你在 CoppeliaSim 里给关节起名为 `Joint_1`，代码也要改成对应名称。
